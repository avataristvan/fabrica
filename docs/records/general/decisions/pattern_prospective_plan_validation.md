Rule: Prospective thinking as plan validation — name the dilemma before implementing something.
When: Before any implementation that creates new states or affects people/systems.
Why: A named dilemma can be resolved or consciously accepted before implementation. An unnamed dilemma leads to unexpected consequences that can afterwards only be repaired.
