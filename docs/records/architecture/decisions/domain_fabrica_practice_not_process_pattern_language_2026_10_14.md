Decision: Fabrica is a practice, not a process. Definition: "Fabrica is a practice that lets humans and agents learn from their own work: experience is captured at the boundaries of the work, kept with its reasons, and brought back when a situation calls for it. It runs alongside whatever method a team uses to do the work." Form, under docs/fabrica/, in two parts plus the tool: (1) core.md, 2-3 pages: the values and what Fabrica is not, the lineage, the definition, the three kinds of knowledge, roles, rituals, artifacts, only what must be there; (2) patterns/, a pattern language after Christopher Alexander: each pattern with name, problem, forces, solution, status (proven / on probation / convention) and evidence linking to records; the former manifesto principles become patterns; (3) ai-mem is the reference implementation for Claude Code. There is no separate manifesto any more: with the user's agreement (2026-10-14) it was folded into core.md and kept as a source, docs/sources/fabrica_manifesto_draft_2026_10_10.md (draft v0.1). docs/epistemology-framework.md became a source (origin), docs/sources/epistemology_framework.md, no longer a current doc. This replaces the earlier plan of a guide.md shaped like the Scrum Guide (domain_framework_named_fabrica_2026_10_10); the name decision there still holds.
Why: The Scrum Guide's discipline (a short, tool-independent, deliberately incomplete core) fits, but its shape does not: Scrum is a work process with its own cadence and timeboxes; Fabrica has none, its rituals sit at the boundaries of other work, so in Scrum form it would look like a competitor to Scrum/BMAD (the same confusion as in domain_bmad_vs_ai_mem_epistemology_2026_09_25, whose three-layer picture places Fabrica as the layer beside planning artifacts). A guide also sounds finished while several practices are on probation (archivist acceptance closed as FAIL, the retrieval trigger only partly solved); patterns carry their status. The pattern form fits the name (Alexander's pattern language comes from building; a fabrica built cathedrals) and turns the records into the documented proof (domain_fabrica_records_public_as_self_proof_2026_10_10). The manifesto was folded in because a separate values document beside core.md duplicated it and read as a second authority.
Scope: docs/fabrica/ (core.md written; patterns/ and README Fabrica-first remain, see todo_split_manifest_and_name_framework), docs/sources/ for the two moved origin texts. Decided with the user 2026-10-14; manifesto folded into core.md the same day.
