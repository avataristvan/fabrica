Decision: Hooks enforce THAT a ritual happens. Roles decide HOW. Planned hooks: SubagentStop checks that a [retro] block carries records_consulted and record_candidates. `mem lint` runs when records changed. At session end, a reminder to run /reflect when work was done. These hooks never inject record content. They only check or remind.
Why: ai-mem's main operational risk is convention fragility: orchestrator-only writes, [retro] blocks and mem_dream are kept by convention, not code (anti_pattern_convention_fragility_ai_mem_2026_10_04 in collection `workspace`, from dev_stack_assessment_2026_05). The plugin direction (archivist, handoffs, /reflect, handoff protocol) adds more convention. Judgment cannot be code-enforced, but call points can. This is not the retired push hooks: those injected content regardless of the situation, these enforce a ritual. Organisations keep the ADR ritual alive the same way, with PR templates and CI checks rather than good intentions.
Scope: plugin hooks/, the [retro] contract, `mem lint`; see docs/reference/hooks.md for the shipped hooks. Measure whether the hooks raise the rate of non-'none' records_consulted and record_candidates.
