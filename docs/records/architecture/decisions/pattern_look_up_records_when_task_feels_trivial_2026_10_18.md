Rule: An agent should get curious whenever it would decide differently than a record might suggest: when the task feels trivial but a record might say otherwise, that is the moment to look (ask the librarian or read the records).
When: Writing agent instructions and librarian trigger points; an idea from spot-check S1 of the seniority run, not yet tested.
Why: In the seniority run the records were read in only about half of the runs even when available ([eval_seniority_available_not_used_confirms_pull_gap_2026_10_18](../../evaluation/learnings/eval_seniority_available_not_used_confirms_pull_gap_2026_10_18.md)); the trigger must name an observable moment ([learning_trigger_must_name_observable_moment_2026_10_10](../learnings/learning_trigger_must_name_observable_moment_2026_10_10.md)).
