Decision: The archivist is the default writer of records, not the only door. Hand-written records stay allowed and readable. Adopting them is an archivist task: normalise them to the record format, regenerate INDEX.md, set edges. Lessons are NOT promoted into agent definitions. Those stay lean, and only the Navigator edits them, by hand. A lesson that had to be learned a third time (third-time rule) signals failed retrieval, not a missing promotion. The archivist sharpens the record's `cue:` (the situation in which it helps) and checks whether a pull point is missing. Consolidation shifts accordingly: it writes good cues, which prepares future recognition.
Why: Separating who (roles), what (records, agent definitions) and how (the tools a role uses) keeps consolidation from being a step someone has to remember to run. Promoting lessons into an agent definition is push by another name: the definition loads into every run whether the situation fits or not. It grows context and noise, like a retired auto-inject. An agent should search its own memory at its boundary instead (domain_why_travels_with_chunk_spec_2026_10_10). The cue is the closest functional analogue of human recognition ('I have been in this situation before'). So the fix for a lesson that is not recalled is a better index, not a bigger prompt. Hand-written records already exist in three areas (learning_handwritten_records_drift_from_format_2026_10_10). The third-time rule comes from Chelsea Troy's practice 4 (pattern_anti_corruption_layer_moment_2026_10_10 in the interview-notes project).
Scope: roles of Fabrica (librarian reads, archivist writes). The mechanism part (ai-mem's `mem` and `mem-dream` as the archivist's tools, `mem lint` normalising drift) is its own record (domain_archivist_mechanism_mem_and_mem_dream_2026_10_11). Revised twice on 2026-10-10: 'only writer' became 'default writer', and the promotion of lessons into agent definitions was dropped at the Navigator's objection.
