Observed: The starting question on 2026-10-10 was how ai-mem could give the agent something like experience: knowledge that situational context triggers, the way it does in a living being. An agent has no cheap recognition signal. Pushed content (ranker, autoinject) fired without regard to the situation. What works is pull at fixed points by a role with judgment. Organisations have no recognition either. They keep memory through rituals at boundaries (ADR reviews, handoffs, retros), which is what DDD context maps and Team Topologies describe. The ai-architecture area already frames the Navigator's AI work in those terms.
Cause: Interpretation, not measurement. Recognition is not available to the agent, so the working analogue is institutional memory: roles, handoff artifacts and a published format, not a simulated personal memory.
