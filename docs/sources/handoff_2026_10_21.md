## Conclusions

All conclusions are unverified (see above).

1. Mechanism: a PostToolUse hook on `Write|Edit|MultiEdit`. It reaches the editing agent at
   the edit, including a coder subagent in a worktree.
2. The hook lives in the ai-mem plugin: `ai_mem/hooks/` plus an entry in `hooks/hooks.json`.
   It follows the hook rules in `docs/reference/hooks.md`: stdlib only, never raises, no stderr,
   stdin treated as untrusted (`pattern_hook_stdin_is_untrusted_2026_10_11`).
3. Purpose of the hint: the agent calls the run out and does not start it.
4. Channel: `hookSpecificOutput.additionalContext`, not a `block` reason, because this is a hint
   and not a finding.
5. Frequency: on every matching edit. No state and no marker file.
6. Detection: the edited file is named `UPGRADING.md`, and its directory contains
   `.claude-plugin/plugin.json` with name `ai-mem`. The check is lexical and follows no
   symlinks, like the containment check in `ai_mem/hooks/lint_after_write.py`. It covers the
   checkout, worktrees and clones.
7. Hint text, roughly: "UPGRADING.md changed: the full acceptance run
   (scripts/upgrade_acceptance/run.sh <empty-scratch>) is due. Do not start it; call it out in
   your report." No record text in the hint.
