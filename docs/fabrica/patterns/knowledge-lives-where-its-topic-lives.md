# Knowledge lives where its topic lives

**Status: convention**

## Problem

A central knowledge store does not know which work it serves. Knowledge kept per person is lost when the person goes.

## Forces

- Topics span projects.
- Links across boundaries can break.

## Solution

A record lives in the nearest folder that holds the work it is about: its *area*. Links across areas use the relative path. Whose view a record holds goes into `perspective:`, not into where it is stored. A finding about something outside the current work goes to the area of that thing.

## Status

Convention. Decided and in use. The user describes the effect as a game changer; that is an observation, not a measurement.
