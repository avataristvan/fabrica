Decision: install.py's register_claude() now recovers an already-installed AI_MEM_WORKSPACE_ROOT prefix (via new `_existing_workspace_root()`) when a re-run's interactive prompt is left blank, instead of silently overwriting the SessionStart/PostToolUse hook commands with no prefix.

Why: exodeck-c1 (parallel session) reported the SessionStart hook resolving a legacy `repo.ExoDeck` collection for a nested git repo instead of the workspace-root-based `repo.ExoDeck-project.ExoDeck` its CLAUDE.md actually uses. Investigation on this machine found the *design* was already correct (detect_repo_context() checks AI_MEM_WORKSPACE_ROOT before git fallback; install.py threads it into hook commands since hooks don't inherit the MCP server's env block -- see key_invariants) but NOT actually applied: `~/.claude.json`'s mcpServers.ai-mem.env had AI_MEM_WORKSPACE_ROOT=/home/istvan/workspace correctly, but `~/.claude/settings.json`'s SessionStart/PostToolUse hook commands had no prefix at all, so hooks were silently back on git-based fallback naming for every project, not just ExoDeck. Root cause: `prompt_workspace_root()` re-prompts on every install.py run with no `--workspace-root` flag; `update_mcp()` already preserves the MCP entry's existing env block when the prompt comes back blank, but the hook-command builder had no equivalent protection -- a routine reinstall (e.g. for an unrelated fix) silently regressed the hook while leaving the MCP server looking fine.

Scope: install.py -- new `_existing_workspace_root(settings_path, module)` parses the currently-installed hook command for an `AI_MEM_WORKSPACE_ROOT=` prefix; `register_claude()` falls back to it when this run's `workspace_root` is empty, before building `env_prefix`. Manually repaired `~/.claude/settings.json` on this machine (both hook commands) since the installed state predates this fix. Tests: tests/test_install.py (3 new: recovered from installed command, empty when absent, empty when settings.json missing). Full suite 511/511 passing. Uncommitted as of 2026-09-27.
